# 竞品调研：建材行业 B2B / 商户展示类平台

> 调研时间：2026-10。目的：对照头部平台与同类小程序，提炼功能与风格借鉴点，指导"建材商户平台"迭代。

## 一、头部 B2B 平台

### 1. 小胖熊（上海米居，辅材 B2B 头部，近 4 亿美元融资）

- 定位：装修辅材一站式采购（水电/瓦工/木工/涂料），SKU 8 万+，合作品牌：伟星、兔宝宝、立邦、公牛等
- 核心功能：
  - **拍照识图找货**：上传建材实拍图自动匹配货品，不用输名称
  - 按装修阶段/材料分类浏览 → 选规格 → 报价区间 → 下单
  - 同城仓储 + 自营配送，订单节点实时可视化
  - **价格行情 / 行业资讯**，帮采购方判断时机
  - 正品赔付基金、小额赊购、账期管理
- 对我们的借鉴：
  - ✅ 价格行情/资讯 → 我们已有"内容管理"模块，可扩展为行情公告
  - ⏸ 拍照识图、赊购账期 → 重运营重资金，暂不做

### 2. 中装速配（全屋建材供应链，B+ 轮）

- 定位：面向装企的全屋材料供应链 + SaaS 管理系统（物流跟踪、B2B 商品对接、城市服务商数据）
- 对我们的借鉴：偏大 B 生意，模式不同；其"商户端 SaaS 数据看板"思路我们已有雏形

### 3. 齐家网（装企赋能）

- 向装企卖 SaaS + 营销工具（大数据分析、星级评价排名、保障计划"齐家保"）
- 借鉴：**商户星级/排名** 可以作为我们后续的商户曝光排序依据（浏览量、成单口碑）

## 二、建材市场小程序的通用模式（与我们最对口）

行业共识（多家小程序服务商总结）：

> **建材大件商品，小程序只做"线上展示 + 线索分发"，看样、谈价、提货全部线下完成。**
> 典型形态：市场商户名录 + 商户上传产品图和报价 + 客户提交询价/拨号 → 商户收到线索跟进。

这正是我们"电话联系 + 免费入驻 + 不做在线支付"的方向，**验证正确**。

同类功能清单（多平台汇总）：

| 功能 | 说明 | 我们现状 |
|---|---|---|
| 商户名录 + 商品展示 | 按市场/品类找档口 | ✅ 已有 |
| 一键拨号 + 导航到店 | 线上留线索，线下成交 | ✅ 拨号已有（含记录），**导航没做** |
| 自助询价表单 | 数量/面积/工程类型一键提交，商户收线索 | ❌ 没做 |
| 分级价格（零售/经销/工程价） | 登录身份自动匹配批发底价 | ❌ 复杂，暂缓 |
| 老客推荐返佣 | 分销拓客 | ❌ 暂缓 |
| 市场活动/公告发布 | 平台发促销通知 | ⚠️ 内容管理可扩展 |
| 求购/清仓/招商信息板 | 供需双向撮合（北方五金网做法） | ❌ 可做二期 |
| 客户采购档案 | 浏览/询价记录沉淀，方便复购回访 | ✅ 已有雏形（浏览/转发/电话记录） |
| 商户星级/排名 | 按活跃度、口碑排序曝光 | ❌ 可用浏览/电话数据做 |

## 三、风格层面观察

- **色调**：批发/交易类小程序普遍用**橙色/黄色主色调**（交易感、价格感强），价格数字用红/橙大字；我们目前是蓝色系（#409eff），偏工具感
- **布局**：大图卡片流 + 底部固定操作栏（电话 + 主行动按钮），与用户发的二手车竞品截图一致
- **信息密度**：列表卡片直接带统计（浏览/电话），商户对"曝光数据"非常敏感（用户截图红圈也印证）

## 四、建议迭代优先级

1. **导航到店**：商户主页/详情页加"到店导航"（wx.openLocation，工作量极小，行业标配）
2. **询价表单**：产品详情页"聊价格"→ 留资表单（数量、说明、微信号）→ 商户端"询价线索"列表。电话之外的第二条线索通道，且留资可回访
3. **市场公告**：平台端内容管理加"公告"类型，小程序首页顶部滚动展示（招商政策、市场活动）
4. **商户热度排序**：商户列表按浏览+电话热度加权排序，替代纯浏览量
5. **换暖色调**：小程序主色从蓝改橙（交易氛围），需用户拍板
6. 二期：求购信息板、商户星级
